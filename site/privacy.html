Privacy policy

Last updated: July 26, 2026

What the extension processes

The extension reads the ICS calendar item selected by the user. Calendar fields may contain a title, description, start and end times, location, recurrence information, attendee names, and attendee email addresses.

Where the information goes

The ICS data is parsed locally in Firefox. When the extension opens an event draft, the relevant calendar fields are placed in an HTTPS URL sent directly to calendar.google.com. Google receives that information and handles it under Google’s own terms and privacy policy. The user reviews the draft before choosing whether to save it.

What the developer receives

The extension does not send data to the developer, use analytics, operate a backend service, create an extension account, or store a copy of calendar data outside the browser.

Updates

Firefox checks this website for signed extension updates. Update checks contain the normal web request information needed to serve a file, but do not contain calendar event data.

Contact

Questions and reports can be submitted through the project issue tracker.

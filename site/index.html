Firefox extension

ICS to Google Calendar

Turn calendar downloads into editable Google Calendar drafts without uploading the ICS file to an intermediary service.

Install version {{VERSION}}

Requires Firefox 140 or newer.

One click from calendar file to draft

  1. Click an ICS link, or use the link’s context menu.
  2. The extension parses the event locally in Firefox.
  3. Review the prepared event in Google Calendar and press Save.

Local parsing, transparent handoff

There is no extension account, analytics, or developer-operated server. Event fields are sent directly to Google Calendar only to create the draft you requested.
